# Costs

Costs shows what your Bots' work costs, by day, week and month.

Work on a plan is **not billed per message**. A plan has a 5-hour window and a weekly allowance. Each one starts over by itself at the time shown.

Money is shown for work paid with an API key. Work on a plan is shown as an estimate.
