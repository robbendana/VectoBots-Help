# Bot templates

A template is one small data file for one Bot: its name, face and instructions.

It holds no memory, no keys, no chats and no code. You can export a Bot as a template, or import one to add a Bot.

Before a template is added you see everything in it. VectoBots does not check it for you, so read it first. The new Bot uses this server's usual AI, not the one in the file.
