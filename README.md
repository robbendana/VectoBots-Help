# VectoBots help site

The articles behind every **Learn more** link in the app. Plain Markdown, built by GitHub Pages (Jekyll).

- English: `<topic>.md` is served at `/<topic>/`. Spanish: `es/<topic>.md` at `/es/<topic>/`.
- The app builds each link from `MB.helpBase` in `web/controls.js`. Change that one line when the site gets its own address.
- Write for users: what the feature does, what it costs, what it never does. Never describe how memory or the server works inside.
- Publishing: copy this folder to the root of the public help repository (Pages: deploy from the main branch). Nothing is published from this repository.
