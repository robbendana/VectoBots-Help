# Voice calls

Talk to a Bot out loud.

- Calls use **your own account** with the voice provider, so you pay the provider directly, the price per minute is shown in Settings.
- The call goes from your device straight to the provider.
- Speed changes the pitch a little. A new voice starts on your next call.
- Keys can only be added once the server is set up for keys.
