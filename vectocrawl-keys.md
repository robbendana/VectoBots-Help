# Better results with keys

You can paste a key from a search service for better results. Keys are optional.

- A key is stored safely and **never shown again**.
- The service **bills you, not us**.
- **Brave Search:** best first choice, about $5 per 1,000 searches, with a small free credit each month.
- **Tavily:** made for AI, 1,000 free searches a month.
- **Exa:** finds pages by meaning, small free credit each month.
- **Firecrawl:** reads hard pages, paid plan from about $16 a month.
- **Jina Reader:** raises the free page-reading limit.
- **Daily limit:** calls with a paid key stop for the day at the number you set. Free search is not counted.

Keys can only be saved once the server is set up for keys.
