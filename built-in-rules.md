# Built-in rules

These rules set how every Bot writes to you: the answer first, in short plain words, one question at a time.

- You can read them on the Rules page.
- **Your own rules come first.** The built-in rules fill in what yours do not cover.
- Approval rules (what Bots may do without asking) are separate. You set them on the same page.
