# Mejores resultados con claves

Puedes pegar una clave de un servicio de búsqueda para obtener mejores resultados. Las claves son opcionales.

- Una clave se guarda de forma segura y **nunca se vuelve a mostrar**.
- El servicio **te cobra a ti, no a nosotros**.
- **Brave Search:** la mejor primera opción, unos $5 por 1,000 búsquedas, con un pequeño crédito gratis al mes.
- **Tavily:** hecho para IA, 1,000 búsquedas gratis al mes.
- **Exa:** encuentra páginas por significado, pequeño crédito gratis al mes.
- **Firecrawl:** lee páginas difíciles, plan de pago desde unos $16 al mes.
- **Jina Reader:** sube el límite gratis de lectura de páginas.
- **Límite diario:** las llamadas con clave de pago se detienen en el día al llegar al número que fijes. La búsqueda gratis no cuenta.

Las claves solo se pueden guardar cuando el servidor está listo para guardar claves.
