# Conecta GitHub

Deja que los Bots trabajen en tus proyectos de GitHub.

- La primera vez, GitHub muestra **un solo botón Crear** para la App de VectoBots. Después eliges qué proyectos pueden ver los Bots y regresas aquí.
- Al iniciar un proyecto, tus Bots obtienen **su propia copia en el servidor**.
- Tu trabajo se guarda en GitHub **solo cuando tú lo indicas**.
