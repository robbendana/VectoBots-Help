# Instala la app

Pon VectoBots en tu pantalla de inicio para que se abra a pantalla completa, como una app.

- **Chrome o Edge:** usa el botón Instalar de aquí, o abre el menú del navegador y elige **Instalar app**.
- **Safari en iPhone o iPad:** toca Compartir y luego **Agregar a pantalla de inicio**.
- Si solo ves **Agregar acceso directo**, recarga la página una vez y vuelve a mirar.
