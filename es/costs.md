# Costos

Costos muestra lo que cuesta el trabajo de tus Bots, por día, semana y mes.

El trabajo con un plan **no se cobra por mensaje**. Un plan tiene una ventana de 5 horas y un límite semanal. Cada uno se reinicia solo a la hora indicada.

Se muestra dinero del trabajo pagado con una clave de API. El trabajo con un plan se muestra como estimación.
