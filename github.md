# Connect GitHub

Let Bots work on your GitHub projects.

- The first time, GitHub shows **one Create button** for the VectoBots App. Then you choose which projects Bots may see, and come back here.
- When you start a project, your Bots get **their own copy on the server**.
- Your work is saved to GitHub **only when you say so**.
