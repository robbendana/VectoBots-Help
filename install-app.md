# Install the app

Put VectoBots on your home screen so it opens full screen, like an app.

- **Chrome or Edge:** use the Install button here, or open the browser menu and pick **Install app**.
- **Safari on iPhone or iPad:** tap Share, then **Add to Home Screen**.
- If you only see **Add shortcut**, reload the page once and look again.
